# Together v1.2 — Десктопное приложение для двоих ♥

Уютное Windows-приложение для пары: показывает, чем сейчас занят партнёр (активное окно, игра, фильм или статус «Отошёл/AFK»), ведёт совместную статистику времени, имеет встроенный чат с доставкой оффлайн-сообщений, милые интерактивные «сердечки» со звуком и систему автоматических обновлений.

---

## ✨ Основные возможности

- **Статус в реальном времени:** Мгновенно видно, в какой игре, программе или браузере находится партнёр, либо когда он отошёл (AFK).
- **Связь через VPS Relay:** Больше **не нужны** ZeroTier, RadminVPN, белые IP-адреса и настройка брандмауэра! Подключение работает из любой точки мира через выделенный защищённый сервер-ретранслятор.
- **Ключ пары (Pairing Key):** Вы с партнёром вводите один и тот же секретный ключ (например, `tgt-xxxx-xxxx-xxxx`) — сервер автоматически связывает ваши сессии.
- **Встроенный чат с оффлайн-очередью:** Если партнёр сейчас не за компьютером, отправленные сообщения сохраняются на сервере и мгновенно доставятся ему при следующем запуске.
- **Интерактивные сердечки ♥:** Нажатие на сердечко в интерфейсе отправляет романтический визуальный импульс и мягкий звуковой перезвон партнёру на экран.
- **Звуковые уведомления:** Мягкие, комфортные по громкости звуки сообщений (`alarm.wav`) и сердечек (`heart.wav`).
- **Статистика приложений:** Локальный учёт времени в приложениях и играх на SQLite.
- **Автообновления через GitHub:** Кнопка «Проверить обновления» прямо в настройках позволяет в один клик скачать и установить свежую версию без ручной возни с файлами.
- **Работа в фоне:** Приложение аккуратно сворачивается в системный трей Windows и поддерживает автозапуск при старте системы.

## 🚀 Быстрый старт (для пользователей)

1. Скачайте свежий `Together.exe` со страницы [GitHub Releases](https://github.com/Tipochec/together-v5/releases).
2. Запустите файл на своём компьютере.
3. Откройте окно приложения (кликните по иконке сердечка в трее в правом нижнем углу).
4. Перейдите в **⚙ Настройки**:
   - Укажите своё **имя** и выберите **аватарку** (любая картинка обрежется в аккуратный квадрат).
   - Введите одинаковый **Ключ подключения** у себя и у партнёра (например: `tgt-em8s-3k65-4spq`).
   - Нажмите **«Сохранить»**.
5. Как только партнёр запустит приложение со своим именем и тем же ключом — вы мгновенно увидите его карточку онлайн!

## 🛠️ Разработка и запуск из исходников

### Требования
- **ОС:** Windows 10 / 11
- **Python:** 3.10 – 3.12 (рекомендуется 3.12)

### Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Tipochec/together-v5.git
   cd together-v5
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите проект:
   ```bash
   python main.py
   ```

## 📦 Сборка автономного .EXE

Сборка осуществляется через `PyInstaller` с использованием готового конфигурационного файла `together.spec`:

```bash
pyinstaller --clean --noconfirm together.spec
```

Готовый файл `Together.exe` появится в папке `dist/`. Все ресурсы (звуки, иконки) будут упакованы внутрь исполняемого файла.

## 📁 Структура проекта

```text
together-v5/
├── main.py                     # Точка входа, single-instance lock, инициализация
├── together.spec               # Спецификация сборки PyInstaller
├── requirements.txt            # Python-зависимости (pywebview, pywin32, pystray, pillow...)
├── assets/                     # Иконки приложения (.ico, .png)
├── sound/
│   ├── alarm.wav               # Звук нового сообщения в чате
│   └── heart.wav               # Звук отправки/получения сердечка
├── core/
│   ├── version.py              # Текущая версия приложения и репозиторий GitHub
│   ├── updater.py              # Проверка релизов GitHub, скачивание и бесшовное обновление
│   ├── network.py              # Клиент VPS Relay, heartbeat, переподключение, доставка чата
│   ├── tracker.py              # Сканирование активного окна Windows, отслеживание AFK
│   ├── stats.py                # Сбор и хранение статистики открытых программ (SQLite)
│   ├── chat.py                 # Локальная база сообщений чата (SQLite)
│   ├── notifications.py        # Воспроизведение звуков Windows
│   ├── autostart.py            # Управление автозапуском Windows (реестр HKCU)
│   ├── paths.py                # Умное разрешение путей (%APPDATA%/Together в .exe vs локально)
│   ├── app_maps.py             # Каталог известных программ и категорий
│   └── tray.py                 # Иконка и контекстное меню системного трея
└── ui/
    ├── window.py               # Контроллер pywebview, мост между Python и JS
    ├── html.py / styles.py / script.py       # Главное окно (активность, статистика, настройки)
    └── chat_html.py / chat_styles.py / chat_script.py # Отдельное окно чата
```

## 💾 Хранение данных

- При запуске через `python main.py`: настройки `settings.json` и база `stats.db` лежат прямо в папке проекта.
- В собранном `Together.exe`: данные надёжно сохраняются в папке `%APPDATA%\Together\`, поэтому настройки, аватарки и история чата никогда не сбрасываются при обновлениях программы.

---

## 🔒 Безопасность и приватность

- В настройках доступен **Приватный режим** — скрывает названия вкладок браузера, отображая просто «Браузер».
- Можно настроить **список игнорируемых процессов** (системные утилиты, VPN и т.п.), чтобы они не засоряли статистику.
- Сообщения и статусы передаются изолированно внутри виртуальной комнаты вашего `pairing_key`.
